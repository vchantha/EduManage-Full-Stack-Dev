# Repository Structure

- frontend/: Next.js/React application
- backend/: Django/DRF API and domain apps
- infra/: Docker/environment/monitoring/backup configuration
- docs/: architecture, API, database, security, standards, runbooks and ADRs
- scripts/: operational/developer helpers
- .github/workflows/: CI quality gates

The repository root is reserved for orchestration and project-wide configuration.
